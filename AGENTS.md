# AGENTS.md

> Detailed architecture, endpoints, and observability docs are in [CLAUDE.md](CLAUDE.md). Read it first.

## Quick start

```bash
npm install                  # install root + workspaces (run once)
npm run dev                  # start API + frontend via Aspire orchestrator
```

- API: http://localhost:5000 | Frontend: http://localhost:5173
- Swagger UI: http://localhost:5000/api/docs
- **No tests exist.** There is no test runner or test script.

## Project layout

| Path | What it is |
|------|-----------|
| `apphost.ts` | Aspire orchestrator — registers API + frontend, wires endpoints |
| `api/src/index.ts` | **Entire** Express 5 API server (single file, in-memory data) |
| `api/src/instrumentation.ts` | OpenTelemetry setup (auto-enabled by Aspire) |
| `frontend/src/App.tsx` | React 19 app root — owns cart state, defines routes |
| `frontend/src/components/` | All UI components |
| `frontend/src/pages/` | Page-level components (AdminPage) |
| `frontend/vite.config.ts` | Vite config with `/api` proxy to Express |
| `.modules/` | **Auto-generated Aspire SDK. Never edit.** |

## Conventions

- **TypeScript everywhere, ESM modules, strict mode.** All packages use `"type": "module"`.
- **CSS**: component-scoped `.css` files with `vk-` prefix on all class names (e.g., `vk-navbar`, `vk-product-card`). No CSS modules, no Tailwind.
- **Theming**: dark is default. Light mode via `@media (prefers-color-scheme: light)`. Variables in `App.css`.
- **State management**: `useState` + prop drilling only. No Redux/Zustand/Context. Cart state lives in `App.tsx`.
- **Types**: component interfaces are defined locally per file (not shared). Intentional for this demo.
- **Data**: in-memory arrays in `api/src/index.ts`. No database. Resets on restart or `POST /api/reset-demo`.
- **Admin auth**: inline password check against `ADMIN_PASSWORD` env var (default: `demo123`).

## Do not

- **Do not edit `.modules/`** — auto-generated by Aspire SDK.
- **Do not fix intentional demo vulnerabilities** in `api/src/index.ts` unless explicitly asked.
- **Do not add a database, ORM, or state management library.** The in-memory/prop-drilling design is intentional.
- **Do not create shared type files.** Local-per-component interfaces are intentional.
- **Do not run `aspire run`** — use `aspire start`. See [SKILL.md](.github/skills/aspire/SKILL.md).

## Adding new features

**New API endpoint**: add in `api/src/index.ts`. Add `@openapi` JSDoc for Swagger. Admin routes check `password === ADMIN_PASSWORD`.

**New component**: create `frontend/src/components/Name.tsx` + `Name.css`. Use `vk-` prefix. Define props interface locally.

**New page/route**: add route in `App.tsx` inside `<Routes>`. Create page in `frontend/src/pages/`.

**New Aspire resource**: modify `apphost.ts`. Run `npm run lint`. Restart with `aspire start`.
